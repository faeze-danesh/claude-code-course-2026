# Week 2 Reflection

This week I learned how tool use works in AI systems like Claude.

The most important concept was the tool use cycle:
user request → model → tool call → system execution → response back to model → final answer.

I also learned that skills are not just commands, but instructions that guide how Claude should behave when explaining or analyzing code.

Creating the /trace skill helped me understand how devlens connects different parts of the system like index.js, api.js, and tools.js.

Now I understand that AI coding assistants are not just chat tools — they are systems that can interact with code through structured tool calls.
